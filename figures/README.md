**Rebuild.** `python3 make_figures.py` reads only `data/` and writes all twelve files. The output is byte-identical on rerun. `TITLED` in the script switches the titles; the PDFs are 6.5 in wide, which is the paper's text width, so include them at `width=100%`. The CSVs were extracted from the project's logs by a script that asserted each number against its source. Each row's `source` column names that source: a path when the file is in this repository, otherwise a description (project journal, theory run log, grader JSON #id, experiment report), since the project tree itself is not published.

**Reading notes.**
- The local knock-out FLOPs include lazily built plans, so they are approximate.
- In the waterfall, MSE × FLOPs does not equal the score ratio for buckets whose steps lack telemetry; the remainder is the `unsplit_ratio` column. The chain ends at 2.02354e-9, against a graded 2.023603e-9 for G4; the gap is ratio rounding.
- G2 (#337322) completed 99/100 MLPs. The failed MLP is not in the public 50.
- G5 is G4 with a different head and scores ×0.9997 of G4; it is not the submission of the write-up.
